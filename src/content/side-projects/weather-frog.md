This simple Python script displays the weather of a chosen city in a Linux terminal. It uses the requests library to fetch data from the OpenWeatherMap API and then displays the data with the PrettyTable library. A helpful frog also gives other fun information! I also modified my .bashrc so it can be called from any directory. The source code is on my [GitHub](https://github.com/liamjosephnolan/weather).
